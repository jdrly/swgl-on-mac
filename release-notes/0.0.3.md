## SWGL on Mac 0.0.3

On macOS 26 the game shows up again instead of a black screen.

### macOS 26: the game shows up again
- On macOS 26, 0.0.1 and 0.0.2 opened the game to a black screen with only the cursor and sound. Some of the graphics driver's built-in shaders were made only for macOS 27, and macOS 26 refused them. They now come in a macOS 26 version too, and the game draws normally there.
- Nothing changes on macOS 27: it keeps using the newer shaders.

Updating from 0.0.2: SWGL on Mac offers the update by itself within a day, or choose **Check for Updates…** in the SWGL on Mac menu. Coming from 0.0.1, download this version once and drag it into Applications.
