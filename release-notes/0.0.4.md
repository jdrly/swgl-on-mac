## SWGL on Mac 0.0.4

Rosetta installs itself when it's missing.

### Rosetta installs itself
- SWGL on Mac needs Rosetta, Apple's translation for Intel apps, to run the game, and updating to macOS 27 removes it. Without Rosetta, 0.0.3 and earlier stopped with "Could not initialise Wine".
- Now SWGL on Mac installs Rosetta by itself when it's missing: during the first setup, or with a short notification the next time you open the app. Installing it accepts Apple's Rosetta licence.
- If it can't be installed, for example without an internet connection, macOS offers its own install dialog, and SWGL on Mac tells you what went wrong in plain words.
