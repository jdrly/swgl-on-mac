## SWGL on Mac 0.1.0

The game runs again with SWG Legends' new 64-bit client.

### The 64-bit client
SWG Legends now ships its game client as 64-bit, and 0.0.4 stopped it with "Could not compile shader vertex_program/2d.vsh". The new client compiles its shaders while it loads, with Microsoft's D3DX library, and Wine's own version of that library rejected them. SWGL on Mac now downloads Microsoft's `d3dx9_31.dll` from Microsoft's DirectX runtime, once, and the game uses it, so its shaders compile as on Windows.

### Graphics driver update
- d9mt, which turns the game's DirectX 9 into Metal, moves to its latest version, `c9ae56d`, in its 64-bit build.
- It keeps textures until the GPU has finished with them (a fix from SWTOR on Mac), and drawing at 4K costs the GPU less.

### A new Settings window
Settings (SWGL on Mac → Settings…, ⌘,) now has a sidebar with Graphics, Game, Mouse, Updates and Troubleshooting, each on its own page. It fits smaller screens, and you can resize it. Show Metal HUD moved to the Game page; Shift-F9 hides or shows the HUD while you play. Your settings carry over.

### After updating
The first start downloads about 100 MB from Microsoft (a short notification says so), so be online for it.
