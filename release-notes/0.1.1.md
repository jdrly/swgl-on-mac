## SWGL on Mac 0.1.1

The game renders on macOS 26 again.

### No more black screen on macOS 26
On macOS 26, 0.1.0 showed the first loading screen and then stayed black, with the game's sound playing. d9mt, which turns the game's DirectX 9 into Metal, labelled every shader it compiled as made for a newer Metal than macOS 26 supports, so macOS 26 refused all of them and nothing was drawn. d9mt now labels each shader with the Metal version it was actually built for on macOS 26, and keeps the label it had on macOS 27, where nothing changes. The log says which one it chose: `d9mt: AIR metallibs tagged for macOS 26`.

### Graphics driver update
- d9mt moves to its latest version, `73511be`, the same one SWTOR on Mac ships.
- On macOS 27 your compiled shaders carry over. On macOS 26 the shaders 0.1.0 compiled never loaded, so the first start compiles them again and the first areas you visit load more slowly, once.
- It also brings fixes from SWTOR on Mac: textures that the game draws before it has filled them show black instead of random colours, a crash when a draw's vertices run past the end of their buffer, and a wrong picture when part of the screen is copied with anti-aliasing on.
